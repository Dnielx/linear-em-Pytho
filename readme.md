# Python Linear Procedural Scripts

Repositório de estudos em Python focado na escrita de **scripts procedurais lineares**, com execução sequencial de cima para baixo, entrada e saída de dados, cálculos e estruturas condicionais.

## Conceitos aplicados
- **Execução linear**: instruções executadas em sequência, do início ao fim do arquivo.
- **Entrada e conversão de dados (`input()`, `float()`)**: leitura de valores fornecidos pelo usuário e conversão para números decimais.
- **Cálculos e condicionais (`if / elif / else`)**: processamento de expressões matemáticas e tomada de decisão com base nas condições definidas.
- **Saída formatada (*f-strings*)**: exibição clara dos resultados no terminal.

## Como executar localmente
1. Certifique-se de ter o **Python 3** instalado na máquina.
2. Clone ou baixe este repositório para o seu computador.
3. Abra o terminal na pasta do projeto e execute:
   ```bash
   python nome_do_arquivo.py
